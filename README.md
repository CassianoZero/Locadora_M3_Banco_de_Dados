# Locadora M3

Projeto desenvolvido para a disciplina de Banco de Dados.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Funcionalidades

- CRUD de Clientes
- CRUD de Veículos
- CRUD de Reservas
- CRUD de Locações

## Como executar

1. Instalar o XAMPP.
2. Iniciar Apache e MySQL.
3. Copiar a pasta do projeto para:

```
C:\xampp\htdocs\Locadora_M3_Xampp
```

4. Importar o arquivo banco.sql no phpMyAdmin.

5. Acessar:

```
http://localhost/Locadora_M3_Xampp/
```
